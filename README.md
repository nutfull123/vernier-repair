# Vernier แจ้งซ่อม

เว็บแอปสำหรับแจ้งซ่อมอุปกรณ์ Vernier บนมือถือ (Android และ iPhone) ถ่ายรูป สแกน S/N จากบาร์โค้ด ส่งงานเข้าคิวซ่อม บันทึกวิธีซ่อม และค้นประวัติย้อนหลังได้

ข้อมูลเก็บใน Google Sheet และรูปเก็บใน Google Drive ของบัญชี Google ที่ติดตั้ง ไม่มีค่าใช้จ่าย

**เปิดใช้งาน:** https://nutfull123.github.io/vernier-repair/ (GitHub Pages อัปเดตเองทุกครั้งที่ push ขึ้น branch `main`)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css`, `app.js` | หน้าเว็บแอป |
| `config.js` | ใส่ลิงก์ Apps Script (ขั้นที่ 3) |
| `manifest.webmanifest`, `sw.js`, `icons/` | ทำให้ "เพิ่มลงหน้าจอหลัก" แล้วเปิดเต็มจอเหมือนแอป |
| `apps-script/Code.gs` | หลังบ้าน วางใน Google Apps Script |
| `apps-script/Products.gs` | รายชื่ออุปกรณ์ 196 รายการ ดึงจาก vernier-thai.com เมื่อ 14 พ.ย. 2569 |
| `tools/` | สำหรับทดสอบในเครื่อง ไม่ต้องอัปโหลด |
| `mockup/ui-mockup.html` | ตัวอย่างหน้าจอที่ใช้ตกลงแบบ |

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### 1. สร้าง Google Sheet

1. เปิด [sheets.new](https://sheets.new) ด้วยบัญชี Google ที่จะใช้เก็บข้อมูล
2. ตั้งชื่อไฟล์ เช่น `Vernier แจ้งซ่อม`

### 2. ใส่โค้ดหลังบ้าน

1. ใน Sheet กดเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `apps-script/Code.gs` ทั้งไฟล์
3. กด **＋** ข้างคำว่า "ไฟล์" → **สคริปต์** ตั้งชื่อ `Products` แล้ววางเนื้อหาจาก `apps-script/Products.gs`
4. กดบันทึก (ไอคอนแผ่นดิสก์)
5. เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **เรียกใช้ (Run)**
6. Google จะขอสิทธิ์ กด **ตรวจสอบสิทธิ์** → เลือกบัญชี → ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ (ชื่อโปรเจกต์)** (เป็นสคริปต์ของคุณเอง) → **อนุญาต**

กลับไปที่ Sheet จะเห็นแผ่นงานใหม่ 4 แผ่น:

- **Tickets** เก็บใบแจ้งซ่อมทั้งหมด ห้ามแก้หัวตาราง
- **Products** รายชื่ออุปกรณ์ เพิ่ม ลบ หรือแก้ได้เลย เช่น เพิ่มรุ่นเก่าอย่าง LabQuest 2
- **Staff** รายชื่อพนักงาน **แก้เป็นชื่อจริงของทีม** ก่อนใช้งาน (หนึ่งชื่อต่อหนึ่งแถว)
- **Config** ชื่อผู้ใช้ (`admin`), รหัสผ่าน (`1234`), อีเมลที่รับแจ้งเตือน (ตั้งเป็นอีเมลของบัญชีนี้ให้แล้ว) เปลี่ยนได้ทุกเมื่อ มีผลทันที

### 3. เปิดใช้หลังบ้านเป็นเว็บ

1. ในหน้า Apps Script กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **เรียกใช้ในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
5. เปิดไฟล์ `config.js` ในโปรเจกต์ แล้ววางลิงก์:

   ```js
   window.API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```

"ทุกคน" หมายถึงทุกคนที่มีลิงก์ส่งคำขอมาได้ แต่ทุกคำขอยังต้องมีชื่อผู้ใช้และรหัสผ่านที่ตรงกับแผ่น Config

### 4. วางหน้าเว็บออนไลน์

เลือกทางใดทางหนึ่ง ทั้งสองทางฟรี:

- **Vercel:** สร้างโปรเจกต์ใหม่แล้วอัปโหลดโฟลเดอร์นี้ (ไม่ต้องตั้งค่า build)
- **GitHub Pages:** อัปโหลดไฟล์ขึ้น repository แล้วเปิด Pages ที่ Settings → Pages

ได้ลิงก์เว็บแล้ว นำไปใส่ช่อง `appUrl` ในแผ่น Config เพื่อให้อีเมลแจ้งเตือนมีปุ่มเปิดหน้ารอซ่อม

### 5. ติดตั้งบนมือถือ

- **iPhone:** เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดลิงก์ใน Chrome → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

## เมื่อแก้โค้ดหลังบ้าน

วางโค้ดใหม่ใน Apps Script แล้วกด **Deploy → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ → เวอร์ชัน: เวอร์ชันใหม่ → Deploy** ลิงก์ `/exec` จะเหมือนเดิม ไม่ต้องแก้ `config.js`

## ข้อจำกัดที่ควรรู้

- **พื้นที่:** บัญชี Google ฟรีได้ 15 GB ใช้ร่วมกับ Gmail และ Photos รูปจากมือถือไม่ย่อขนาด ใบละ 2 รูปประมาณ 8 MB จึงเก็บได้ราว 1,800 ใบ ดูพื้นที่ที่เหลือได้ที่ [one.google.com/storage](https://one.google.com/storage)
- **อีเมลแจ้งเตือน:** บัญชีฟรีส่งได้วันละ 100 ฉบับ
- **รูปภาพ:** ตั้งเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้แอปแสดงรูปได้ ลิงก์รูปเดายากมาก แต่ถ้ามีคนได้ลิงก์ไปก็เปิดดูได้
- **รหัสผ่าน:** ทุกคนใช้รหัสเดียวกัน อย่าแชร์ลิงก์เว็บออกนอกบริษัท ถ้าลิงก์หลุด ให้เปลี่ยนรหัสในแผ่น Config แล้วทุกเครื่องจะต้องเข้าสู่ระบบใหม่
- **ลบใบแจ้ง:** แถวใน Sheet หายทันที รูปจะอยู่ในถังขยะของ Drive อีก 30 วัน ถ้าลบผิด ยังกู้ข้อมูลใน Sheet ได้จาก **ไฟล์ → ประวัติเวอร์ชัน**
- **ใช้พร้อมกัน:** รองรับทีม 7–10 คนสบาย การบันทึกมีการล็อกกันข้อมูลทับกัน

## ทดสอบในเครื่อง (สำหรับคนแก้โค้ด)

ต้องมี Node.js 18 ขึ้นไป

```bash
node tools/test-backend.mjs
```

```bash
node tools/dev-server.mjs
```

คำสั่งแรกทดสอบ `Code.gs` จริงกับ Google Sheet และ Drive จำลองในหน่วยความจำ คำสั่งที่สองเปิดแอปที่ http://localhost:5173 (ล็อกอิน `admin` / `1234`) ข้อมูลหายเมื่อปิดเซิร์ฟเวอร์ และไม่มีการส่งอีเมลจริง
